DAY 7 CHALLENGE: DATA TIDYING & RESHAPING WITH TIDYVERSE
====================================================================

OVERVIEW:
In this exercise, you will tidy two messy datasets (`weather_wide` and `station_alerts`) using modern `tidyverse` reshaping functions.

--------------------------------------------------------------------
TASK 1: TIDY WEATHER DATA & CALCULATE TEMPERATURE SPREAD
--------------------------------------------------------------------
Target Dataset: `weather_wide`

1. Reshape the `weather_wide` dataset from wide to long format using `pivot_longer()`.
2. Extract the column headers starting with "Max" and "Min" so that:
   - Temperature values fall under two distinct metric columns: `Max_Temp` and `Min_Temp`.
   - The embedded dates are extracted into a dedicated `date` column.
3. Add a new calculated column named `temp_spread` which equals `Max_Temp` minus `Min_Temp`.

Expected Output Columns for `tidy_weather`:
- station_id
- date
- Max_Temp
- Min_Temp
- temp_spread

--------------------------------------------------------------------
TASK 2: UNPACK STATION ALERT LOGS
--------------------------------------------------------------------
Target Dataset: `station_alerts`

1. Inspect the `log_entry` column, which contains concatenated strings separated by underscores (e.g., "2026-08-01_HIGH_Overheat").
2. Use `separate_wider_delim()` to split `log_entry` by the underscore ("_") delimiter into three new distinct columns:
   - `date`
   - `status_level`
   - `event_type`

Expected Output Columns for `tidy_alerts`:
- station_id
- date
- status_level
- event_type
